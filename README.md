# 23-manju-studio

23系列漫剧制作合并技能。只安装一个SKILL，收到新剧本后先显示**可多选菜单**，再制作选中的内容。

| 编号 | 功能 | 交付 |
|---|---|---|
| 1 | 全剧资产设计 | 3D国漫CG资产提示词、可浏览HTML与完整PDF |
| 2 | 动态系统框 | 系统文案提取、动态设计、真实Alpha透明MOV |
| 3 | 动态名牌 | 人物身份与场景名牌、透明MOV |
| 4 | Seedance 2.5分镜优化 | 优化基础镜头提示词，保留对白和剧情 |
| 5 | 漫剧封面 | 5版不同设计，全部竖向3:4 |
| 6 | BGM导演 | Incompetech优先、按需原创配乐方案、剪映音量与关键帧 |

当前版本：**1.1.0**。

## 使用

安装后提交剧本并说“使用23-manju-studio”。菜单支持`1+3+6`、`资产和BGM`或`全部`。默认处理所提供的全剧本；可明确限定集数。新剧本先选模块，同一项目续做沿用选择，缺失参数集中询问。

普通资产只交付提示词；系统框/名牌交付视频；封面默认实际成图。选中分镜优化但只有剧本时，会询问提供基础稿，或授权先建立基础分镜。缺少某个模块的输入不阻塞其他已选模块。

## 安装

把本仓库完整目录放到Codex技能目录，文件夹命名为`23-manju-studio`，确保`SKILL.md`位于该文件夹根部。无需同时安装原来的六个技能；建议备份后将旧入口移出技能目录，避免重复发现。

可用Git克隆到目标技能目录：

```text
git clone https://github.com/verse-23/23-manju-studio.git <技能目录>/23-manju-studio
```

入口见[SKILL.md](SKILL.md)，运行依赖见[运行与来源](runtime-and-sources.md)。无需安装未使用模块的额外依赖。

## 保留的制作偏好

3D国漫CG、人物白底三视图＋五官半身近照、高颜且有辨识度、强化动漫剪影与发型设计、不写鞋底描述；无校服及性化/血腥呈现。资产/项目默认16:9与2K目标；封面3:4。BGM优先在Incompetech找具体曲目，按需补其他来源或原创方案，不参考Apple Music/iTunes，配音基线为响度统一−23 LUFS后+10 dB，音乐按实际版本试混或测量。

Images 2.5 / Sunburst为历史目标模型偏好，不代表当前工具一定可调用或保证原生2K。透明视频须验证解码Alpha；剪映兼容性只有实际导入后才算验证。技能不能保证平台审核、点击率或一次生成成功。

本仓库仅含通用工作流、工具、模板与来源通知，不包含业务剧本、第三方参考图片或机器配置。融合版本见[module-manifest.json](module-manifest.json)；第三方许可通知保留在相应模块内。
